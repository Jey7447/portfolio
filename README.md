# Jesse Briska — Portfolio

Premium technical portfolio built with Next.js, TypeScript, CSS and Framer Motion.

## Stack

- Next.js 16
- React 19
- TypeScript
- Framer Motion
- next-themes
- Lucide React
- ESLint + eslint-config-next

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Validate before deployment

```bash
npm run lint
npm run build
```

## Portfolio structure

- `/` — editorial homepage
- `/work/careplus` — CarePlus Medical Centre case study
- `/work/dmda` — DMDA Voting Portal case study
- `/work/bakery` — Bakery Order Tracker case study
- `/work/productforge` — ProductForge AI case study

## Deployment

The project is prepared for Vercel deployment. Before the first production deployment:

1. Run `npm install`.
2. Run `npm run lint`.
3. Run `npm run build`.
4. Deploy the `main` branch to Vercel.
5. Verify desktop and mobile layouts on the production URL.
6. Verify all case-study routes and external links.
